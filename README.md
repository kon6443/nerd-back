# nerd-back

원티드 AI Championship 2026 참가작 백엔드.

## 스택

- NestJS (Node.js / TypeScript)
- 배포: OCI A1 (ARM64, 12GB RAM / 2 OCPU)

## 일정

| 마일스톤 | 날짜 |
| --- | --- |
| 참가 접수 마감 | 2026-09-18 |
| 기능 동결 | 2026-09-17 |
| 과제 제출 마감 | 2026-09-20 23:59 |
| 예선 심사·투표 | 2026-09-21 ~ 10-05 |
| 데모데이 | 2026-10-17 |

심사 기간(9/21~10/17) 동안 배포 링크가 끊기면 심사 대상에서 제외된다.
무중단 운영과 API 예산 상한 폴백은 선택이 아니라 요구사항이다.

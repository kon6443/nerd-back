# My Story

내가 동화 속 주인공이 되는 개인화 동화 서비스입니다.

사전에 준비된 동화 콘텐츠를 기반으로 사용자의 얼굴을 주인공에게 적용하고, 동화 속 등장인물과 상호작용하며, 이야기가 끝난 뒤에도 새로운 이야기를 이어갈 수 있습니다.

## 핵심 기능

### 1. 내가 주인공인 동화
사용자는 카메라를 통해 정면, 왼쪽, 오른쪽 얼굴을 촬영합니다. 촬영된 얼굴 정보를 이용해 동화 속 **주인공 한 명**을 사용자 얼굴로 개인화합니다.

갤러리에서 기존 사진을 업로드하는 방식은 제공하지 않습니다.

### 2. 등장인물과 대화
동화를 읽는 중 등장인물을 터치하면 현재 장면을 이해하는 AI 캐릭터와 자유롭게 대화할 수 있습니다.

대화는 본편의 스토리 전개와 결말에 영향을 주지 않으며, 입력창에는 적절한 질문을 유도하는 가벼운 예시를 제공합니다.

예: `늑대야, 지금 어디 가고 있어?`

### 3. 동화 이후의 이야기
본편이 끝난 뒤 비하인드 스토리를 선택하면 이야기를 계속 이어갈 수 있습니다.

후속 이야기는 사전에 정의된 스토리 템플릿을 기반으로 하며, MVP에서는 A/B 두 가지 선택지를 통해 서로 다른 전개와 결말을 경험합니다.

## 사용자 흐름

```text
동화 라이브러리
      ↓
동화 선택
      ↓
얼굴 촬영
(정면 / 왼쪽 / 오른쪽)
      ↓
주인공 얼굴 개인화
      ↓
동화 읽기
      ↓
등장인물 터치 → 자유 대화
      ↓
본편 종료
      ↓
비하인드 스토리 선택
      ↓
A / B 분기 선택
      ↓
후속 이야기 및 결말
```

## 콘텐츠 구조

동화 콘텐츠는 사용자가 작성하는 방식이 아니라 서비스에서 사전에 제작하고 템플릿 형태로 관리합니다.

스토리의 구조와 분기는 미리 정의하고, AI는 얼굴 개인화와 등장인물 대화 등 필요한 영역의 표현을 담당합니다.

```text
Story Template
 ├─ Original Story
 │   ├─ Pages
 │   │   ├─ Text
 │   │   ├─ Image
 │   │   └─ Characters
 │   └─ Character Context
 │
 ├─ Character Interaction
 │   └─ Scene-aware Chat
 │
 └─ After Story
     ├─ Branch A
     ├─ Branch B
     └─ Endings
```

## 핵심 제품 원칙

- **주인공 개인화:** MVP에서는 한 명의 주인공만 사용자 얼굴로 변경합니다.
- **스토리 일관성:** 페이지가 넘어가도 주인공의 얼굴과 외형이 최대한 일관되게 유지되어야 합니다.
- **캐릭터 일관성:** 등장인물의 성격, 말투, 설정은 장면이 바뀌어도 유지되어야 합니다.
- **본편 보호:** 캐릭터 대화는 본편의 사건 순서와 결말을 변경하지 않습니다.
- **통제된 생성:** Story 구조와 분기는 사전에 정의하며 AI가 임의로 전체 스토리를 변경하지 않습니다.

## 기술 스택

| 영역 | 기술 |
| --- | --- |
| Frontend | Next.js (App Router), React, TypeScript |
| Backend | Next.js API / Server Actions |
| Database | Supabase PostgreSQL |
| Storage | Supabase Storage |
| Authentication | Supabase Auth |
| AI | 이미지 생성/편집 API, LLM |
| Deployment | Vercel |

## MVP 범위

- 사전 등록된 동화 콘텐츠
- 동화 라이브러리
- 정면 / 좌측 / 우측 얼굴 촬영
- 갤러리 이미지 업로드 제한
- 주인공 1명 얼굴 개인화
- 개인화된 동화 읽기
- 등장인물 Scene-aware 자유 대화
- 대화 입력 가이드(placeholder)
- 동화 종료 후 비하인드 스토리
- A/B 형태의 후속 스토리 분기
- 서로 다른 결말

## 프로젝트 방향

AI 모델 자체를 만드는 것보다 **사용자가 실제로 자신의 얼굴이 들어간 동화를 읽고, 등장인물과 상호작용하고, 본편 이후의 이야기를 계속 경험하는 것**을 검증하는 것을 목표로 합니다.

동화 본편과 After Story의 구조 및 분기는 사전에 템플릿화하고, AI는 얼굴 개인화와 등장인물 대화 등 필요한 영역에 집중해서 활용합니다.
